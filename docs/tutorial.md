## 第 0 章 · 这套方案是怎么回事

### 你最终会得到什么

1. 一个**免费**的个人网站，有关于、作品、文章三个板块
2. 国内可以直接打开，**不用买服务器、不用备案**
3. 以后更新内容不用碰代码：**在飞书里写文章/传作品，最多 30 分钟后网站自动更新**

### 原理一张图

```text
┌──────────┐      每 30 分钟自动搬运       ┌──────────┐        自动构建        ┌──────────────┐
│   飞书    │ ──────────────────────────▶ │  GitHub  │ ────────────────────▶ │   Cloudflare  │
│ 你的后台   │    （GitHub Actions）        │ 存放代码  │    （Cloudflare Pages）│  你的网站上线  │
└──────────┘                              └──────────┘                       └──────────────┘
     你在这里写作                              不用管它                           访客打开网址
```

用人话讲一遍：

- **飞书**：你的「内容后台」。你在飞书的表格里登记文章/作品，在飞书文档里写正文。
- **GitHub**：一个存放网站代码的地方（全球程序员都在用）。它每隔 30 分钟自动去飞书把你的新内容搬回来。
- **Cloudflare**：免费帮你把网站「挂」到互联网上，给你一个网址，比如 `your-name.pages.dev`。

### 你需要准备的东西

| 东西 | 说明 |
| --- | --- |
| 一台电脑 | Windows 或 Mac 都行 |
| 手机号 / 邮箱 | 用来注册下面的账号 |
| 3 个免费账号 | 飞书、GitHub、Cloudflare（下一章逐个注册） |

> **可选**：如果你想在自己电脑上预览网站，还需要安装 Node.js（见第 2 章末尾）。只想上线的话，全程在浏览器里就能完成，什么都不用装。

## 第 1 章 · 准备工作（注册 3 个免费账号）

这一章全是注册账号，每个 5 分钟左右。**注册时用的用户名/邮箱请记在便签上**，后面要用。

### 1.1 注册飞书

1. 打开 [https://www.feishu.cn/](https://www.feishu.cn/)
2. 点击右上角「**注册**」
3. 选择「**个人版**」（个人使用免费，够用了）
4. 用手机号或邮箱完成注册
5. 建议在电脑上下载并登录**飞书客户端**（后面的操作在客户端里做，比网页版顺手）

> 注册完你会有一个飞书账号，比如手机号 `138xxxxxxxx`。以后写文章都在这里写。

### 1.2 注册 GitHub

1. 打开 [https://github.com/](https://github.com/)
2. 点击右上角「**Sign up**」
3. 填写邮箱 → 设置密码 → 设置用户名（**用英文字母**，比如 `xiaobai-design`，这个用户名后面会出现在你的仓库地址里）→ 完成
4. 邮箱里找到验证邮件，点验证
5. 免费套餐就够，不用付费任何东西

> 国内打开 GitHub 偶尔比较慢，多刷新几次。如果实在打不开，说明网络环境需要「科学上网」，这一步没有别的办法。

### 1.3 注册 Cloudflare

1. 打开 [https://dash.cloudflare.com/sign-up](https://dash.cloudflare.com/sign-up)
2. 用邮箱注册，设置密码
3. 之后可能让你「选择套餐」，选最左边的 **Free（免费）** 即可

## 第 2 章 · 拿到你的网站（复制模板，1 分钟）

网站的外观和代码已经做好了，放在一个「模板仓库」里，你复制一份就变成自己的。

### 2.1 复制模板到自己账号下

1. 确保你已在浏览器里**登录 GitHub**
2. 打开模板仓库：**https://github.com/Xplore-AGI/portfolio-template**
3. 点击页面上方的绿色「**Use this template**」按钮 →「**Create a new repository**」
   （如果没看到这个按钮，点右边「**Fork**」也行，效果一样）
4. Repository name 填：`my-website`（名字随意，用英文，别用中文）
5. 选择 **Public**（公开。Cloudflare 免费版连私有仓库需要额外操作，公开最省事；网站内容本来就是给大家看的）
6. 点绿色「**Create repository**」按钮

完成后你就有了自己的仓库：`https://github.com/你的用户名/my-website`

> 恭喜，代码部分已经完成了 90%。接下来只是「接线」。

### 2.2（可选）在自己电脑上预览网站

> 这一节可以跳过，直接去第 3 章上线。等你以后想折腾了再回来看。

1. 下载安装 Node.js：打开 [https://nodejs.org/](https://nodejs.org/)，下载 **LTS（长期支持版）**，一路「下一步」安装完
2. 把仓库下载到电脑：在你仓库页面点绿色「**<> Code**」按钮 →「**Download ZIP**」，解压到一个好找的文件夹
3. 打开终端（Mac 叫「终端」，Windows 在开始菜单搜「PowerShell」），输入：
   ```bash
   cd 你解压的文件夹路径
   npm install
   npm run dev
   ```
4. 浏览器打开 [http://localhost:4321](http://localhost:4321) 就能看到网站了

## 第 3 章 · 让网站上线（Cloudflare 免费部署）

这一章做完，你就有自己的网址了。

### 3.1 连接仓库

1. 打开 [https://dash.cloudflare.com](https://dash.cloudflare.com)，登录
2. 左侧菜单找到「**Workers 和 Pages**」（Workers & Pages），点进去
3. 点「**创建**」→ 选「**Pages**」标签页
4. 选「**连接到 Git**」（Connect to Git）
5. 点「**连接 GitHub**」，会跳到 GitHub 授权页面 → 点「**Authorize Cloudflare**」同意
6. 回到 Cloudflare 页面，在仓库列表里选中你刚创建的 `my-website` → 点「**开始设置**」

### 3.2 配置构建（就填两格）

| 配置项 | 填什么 |
| --- | --- |
| 项目名称 | 随意，比如 `my-website`（它会成为网址的一部分） |
| 生产分支 | `main`（默认就好） |
| **框架预设** | 如果有下拉框，选 `Astro`；没有就不用管 |
| **构建命令** | `npm run build` |
| **构建输出目录** | `dist` |

> 注意「构建输出目录」填 `dist`，**不要**填 `/dist`，也不要留空。

填完点「**保存并部署**」（Save and Deploy）。

### 3.3 打开你的网站

等 1～3 分钟（第一次要装依赖，会久一点），看到日志最后显示 **Success** 就成功了。

页面顶部会给你一个网址，长这样：

```text
https://你的项目名.pages.dev
```

手机电脑都试试，发给朋友试试。**这个网址就是你的网站**，永久免费。

> 以后每次你更新内容，Cloudflare 会自动重新构建，一般 1～2 分钟后刷新网页就能看到新内容，你什么都不用做。

### 3.4（可选）绑定自己的域名

如果你花几十块钱买了一个自己的域名（比如 `xiaobai.com`），可以绑上：

1. 先在你的域名服务商那里，把 DNS 服务器改成 Cloudflare 提供的两个地址（按它的提示操作）
2. Cloudflare 里进入你的 Pages 项目 →「**自定义域**」→「**设置自定义域**」→ 输入你的域名 → 按提示完成

没有域名就跳过，`pages.dev` 的网址也能一直用。

## 第 4 章 · 把飞书变成你的内容后台

这是整篇教程**步骤最多的章节**（约 20 分钟），做完以后你就拥有一个「写完自动发布」的后台。深呼吸，一步步来。

### 4.1 创建一个飞书「机器人」

你的网站需要一个「搬运工」身份去飞书读你的内容，这在飞书里叫「自建应用」。

1. 打开飞书开放平台：[https://open.feishu.cn/](https://open.feishu.cn/)，用你的飞书账号登录
2. 点「**开发者后台**」→「**创建企业自建应用**」
3. 应用名称填：`我的网站同步`（随意）；图标随便选一个；点创建
4. 创建完成后，进入应用页面，左侧点「**凭证与基础信息**」
5. 你会看到两个关键信息：
   - **App ID**：长这样 `cli_a1b2c3d4e5f6g7h8`
   - **App Secret**：长这样 `k9Xm2Pq8Lw3Rt6Yu1Io5Pa9Sd2Fg4Hj7`

> **把这两个值复制到一个记事本里**，第 5 章要用。这就是「钥匙」的前两把。

### 4.2 给机器人开权限

还是在应用管理页面：

1. 左侧菜单点「**权限管理**」
2. 在搜索框里逐个搜索并**打开**以下 4 个开关（点右侧「开通权限」）：

| 搜索关键词 | 打开的权限 | 干什么用 |
| --- | --- | --- |
| `bitable` | 查看、评论、编辑和管理多维表格 | 读你的内容表格 |
| `docx` | 查看文档 | 读你写的文章 |
| `drive` | 查看、评论云空间中所有文件 | 下载文章里的图片 |
| `wiki` | 查看知识库 | 支持放在知识库里的文档 |

3. 开完权限后，**必须发布应用才生效**：左侧点「**版本管理与发布**」→「**创建版本**」→ 版本号随便填（如 1.0.0）→ 一路下一步 →「**申请发布**」
4. 个人版应用通常**秒过审**，状态变成「已上线」即可

> ⚠️ **最常见的坑**：开了权限但忘记发布新版本，权限不生效，后面同步会报「权限不足」。改完权限永远记得发布一次。

### 4.3 创建知识库和内容表格

现在去飞书建你的「内容后台」。我们的方式：**建一个知识库，所有内容都放它里面**——表格、文章、作品详情，一个入口全管理。

1. 打开飞书 → 左侧「**知识库**」（Wiki）
2. 点「**新建知识库**」，名字随意，比如：`我的网站`，权限默认即可
3. 进入这个知识库 → 点「**+ 新建**」→ 选「**多维表格**」，命名为：`网站内容库`
4. 这个多维表格自带一个数据表，把它重命名为：**作品表**
   （点表格左上角的名字就能改）
5. 再点数据表旁边的「**+**」新建第二个数据表，命名为：**文章表**

> ⚠️ 两个数据表的名字**必须**是「作品表」「文章表」——同步脚本靠表名找它们。以后想改表名可以，但 GitHub 里的 Secrets 也要跟着改（见第 5 章）。

6. 照下面两张表，逐个添加字段：点表格右上角「+」号（或字段名旁的下拉 →「添加字段」）

**作品表字段（13 个）：**

| 字段名 | 字段类型 | 说明 |
| --- | --- | --- |
| 标题 | 多行文本 | 必填，项目名称 |
| 简介 | 多行文本 | 列表页的一句话描述 |
| 封面 | 附件 | 贴一张封面图（建议 3:2） |
| 标签 | 多选 | 如：产品设计 / 品牌设计 |
| 客户 | 多行文本 | 可选 |
| 年份 | 多行文本 | 如 2025 |
| 链接 | 多行文本 | 可选，线上项目地址 |
| 精选 | 复选框 | 勾上表示首页推荐 |
| 日期 | 日期 | 排序用 |
| 发布 | 复选框 | **不勾就不同步** |
| slug | 多行文本 | 可选，自定义网址（英文） |
| 正文 | 多行文本 | 可选，直接写 Markdown |
| 详情文档 | 超链接 | 可选，贴一篇飞书文档链接当正文（优先级高于「正文」） |

**文章表字段（9 个）：**

| 字段名 | 字段类型 | 说明 |
| --- | --- | --- |
| 标题 | 多行文本 | 必填 |
| 简介 | 多行文本 | 可选 |
| 封面 | 附件 | 贴封面图 |
| 标签 | 多选 | 分类 |
| 日期 | 日期 | 发布日期 |
| 发布 | 复选框 | **不勾就不同步** |
| slug | 多行文本 | 可选 |
| 正文 | 多行文本 | 可选，直接写 Markdown |
| 文档 | 超链接 | 可选，贴飞书文档链接当正文（优先级高于「正文」） |

### 4.4 复制表格的链接

多维表格建好后，只需要拿到它的**链接**（不用去找什么 ID，脚本会自己识别）：

1. 在知识库左侧目录里，找到「**网站内容库**」这个多维表格
2. **右键点它的名字 → 「复制链接」**
3. 链接长这样（`wiki/` 开头就对了）：

```text
https://xxx.feishu.cn/wiki/Xx1y2Z3a4B5c6D7e8F9g0H
```

> 到这里你的记事本上应该有 3 样东西：App ID、App Secret、表格链接。马上就用。

## 第 5 章 · 打通自动同步（填 6 把钥匙）

这一章把钥匙填进 GitHub，让搬运工动起来。

### 5.1 填入 Secrets

1. 打开你的仓库 `https://github.com/你的用户名/my-website`
2. 仓库页面顶部点「**Settings**」（设置）
3. 左侧菜单：「**Secrets and variables**」→「**Actions**」
4. 点「**New repository secret**」，然后照下表**逐个添加 6 条**（Name 精确复制，别多空格；Value 粘贴你记事本里的对应值）：

| Name（照抄） | Value（填你的） |
| --- | --- |
| `FEISHU_APP_ID` | 飞书应用的 App ID（`cli_` 开头） |
| `FEISHU_APP_SECRET` | 飞书应用的 App Secret |
| `FEISHU_WORKS_APP_TOKEN` | 粘贴「网站内容库」的链接（4.4 复制的那条） |
| `FEISHU_WORKS_TABLE_ID` | 填表名：`作品表` |
| `FEISHU_POSTS_APP_TOKEN` | 再粘贴一次同一条链接 |
| `FEISHU_POSTS_TABLE_ID` | 填表名：`文章表` |

### 5.2 跑第一次同步

1. 仓库页面顶部点「**Actions**」标签
2. 左侧列表点「**飞书同步**」
3. 点右侧灰色「**Run workflow**」按钮 → 保持 main 分支 → 点绿色「**Run workflow**」
4. 列表最上面出现一条黄色转圈的记录，点进去，等十几秒
5. 变成绿色 **✓** = 同步成功（现在表格是空的，所以显示「没有变更」也正常）

> 以后它会**每 30 分钟自动跑一次**，你不用管。想立刻同步时，就手动点一次 Run workflow。

### 5.3 检查网站

回到你的 `xxx.pages.dev` 刷新看看——模板自带的示例作品和示例文章已经在了。

## 第 6 章 · 写你的第一篇文章

激动人心的时刻。从现在起，**写文章 = 在飞书里建一个文档 + 在表格里贴一个链接**。

### 6.1 写文档

1. 飞书 → 进入你的知识库 → 点「**+ 新建**」→ 选「**文档**」，给它起个标题，比如《我的第一篇文章》（和「网站内容库」放在一起，方便管理）
2. 正常写作。**用飞书自带的排版**（这很重要）：

| 想要的效果 | ✅ 正确做法 | ❌ 错误做法 |
| --- | --- | --- |
| 粗体 | 选中文字按 `⌘B` / `Ctrl+B` | 手打 `**文字**` |
| 标题 | 工具栏选「标题 1 / 标题 2」 | 手打 `## 文字` |
| 列表 | 工具栏的项目符号 / 有序列表 | 手打 `- 文字` |
| 引用 | 工具栏的引用块 | 手打 `> 文字` |
| 图片 | 直接粘贴进文档 | — |

> 「标题 1」「标题 2」在网站上有专门的漂亮样式（大节标题、橙色小节标题）；只是把文字加粗的话，网站上就只是一行粗体，没有标题效果。

3. 写完保存（飞书自动保存，不用管）

### 6.2 关于文档权限（知道就好）

放在**知识库里**的文档，机器人（飞书应用）一般可以直接读，你什么都不用做。

如果以后同步日志报「权限不足 / permission denied」，补救方法：打开那篇文档 → 右上角「**分享**」→ 搜索你的应用名（如 `我的网站同步`）→ 添加为协作者（可阅读）。

### 6.3 在文章表登记这篇文章

1. 打开「网站内容库」→ **文章表**，在第一行填：

| 字段 | 填什么 |
| --- | --- |
| 标题 | 我的网站文章标题（会显示在网站上，可以和文档标题不同） |
| 简介 | 一句话摘要，显示在文章列表（可选） |
| 封面 | 点格子里的 + 上传图片，或直接 `⌘V` 粘贴 |
| 标签 | 顺手建几个分类（可选） |
| 日期 | 今天 |
| **发布** | ✅ **勾上！不勾不会同步** |
| slug | 可选，想自定义网址就填英文如 `my-first-post` |
| 文档 | 贴文档链接（下面单说） |

2. **「文档」字段贴链接的正确姿势**：
   - 在知识库左侧目录里，**右键点这篇文档 →「复制链接」**
   - 粘贴到表格的「文档」格子里
   - **自检**：粘贴后链接显示的文字应该是**你的文章标题**。如果显示「未命名页面」或表格名（比如「网站内容库」），说明复制错了——你复制成别的东西的链接了

### 6.4 发布上线

1. GitHub → Actions → 飞书同步 → Run workflow（或等 30 分钟自动跑）
2. 绿色 ✓ 后，等 1～2 分钟 Cloudflare 构建完
3. 刷新你的网站 → 「文章」页 → 你的文章在了，图片也自动搬过来了

🎉 **至此，你已经拥有「写完即发布」的完整闭环。**

### 6.5 日常管理

| 想做什么 | 怎么做 |
| --- | --- |
| 下线一篇文章 | 文章表里把「发布」的勾去掉，下次同步自动消失 |
| 改文章内容 | 直接改飞书文档，最多 30 分钟自动更新 |
| 改文章网址 | 改表格里的 slug 字段 |
| 删文章 | 表格里删掉那一行（或取消发布） |

## 第 7 章 · 发布你的作品案例

作品和文章是同一套逻辑，只是字段多一点。

### 7.1 登记（作品表加一行）

必填：**标题、年份、日期、发布**；强烈建议：**简介、封面、标签**；其他可选。

封面图建议 3:2 横图，会显示在作品列表的卡片上。

### 7.2 写作品详情

两种方式任选：

- **简单版**：把内容直接写在表格的「正文」字段里（支持 Markdown 语法）
- **推荐版**：像文章一样，在知识库里新建一篇文档写详情，把链接贴到「**详情文档**」字段

### 7.3 推荐的案例写作结构

设计类项目用「八段式」结构很出效果（网站上每段都有专门的样式）：

```text
一、需求背景、分析      （这个项目是什么、为什么做）
二、目标与挑战          （要达成什么、难点在哪）
三、设计策略            （你的思路和切入点）
四、设计过程            （怎么推导的，放过程稿）
五、落地方案            （最终方案，可分几个小节展开）
六、数据与结果          （上线后的数据/反馈，有数字最有说服力）
七、反思与迭代          （哪里可以做得更好）
八、设计验收            （项目交付清单、经验沉淀）
```

在文档里每段用一个「**标题 1**」，段内小点用「**标题 2**」，网站会自动渲染成虚线大节 + 橙色小节的样式。

## 第 8 章 · 出问题了怎么办（踩坑手册）

按「看到什么现象」对号入座。

### 现象 1：Actions 同步红色 ✗

1. 点进那次红色记录 → 点左侧「sync」→ 展开红色报错的那一步看最后几行
2. 常见报错对照：

| 报错关键词 | 原因 | 解决 |
| --- | --- | --- |
| `获取 token 失败` | App ID / Secret 填错 | 回 5.1 检查前两个 Secret |
| `permission denied` / `权限` | 飞书应用权限没开或没发布 | 回 4.2，开权限后**重新发布版本** |
| `not found` / `404` | APP_TOKEN 或 TABLE_ID 填错 | 回 4.4 重新抄地址栏 |
| `push` / `rejected` | 和别人/别的任务同时推送撞车 | 再点一次 Run workflow 就好（已自动处理） |

### 现象 2：同步绿色 ✓，但网站上没我的文章

按顺序检查：

1. **「发布」勾了吗？** 不勾 = 不同步（最常见）
2. **「标题」填了吗？** 没标题的行会被跳过
3. **「文档」链接贴对了吗？** 点表格里的链接，打开的应该是你的文章；如果打开是个表格或「未命名页面」，重新复制（正确方法见 6.3）
4. **文档权限够吗？** 知识库内文档一般没问题；若日志报权限错误，按 6.2 的方法给文档加应用权限
5. 以上都对 → 看 Actions 日志里有没有 `⚠️ ... 已跳过` 的黄色警告，按提示改
6. 还不行 → 等 2 分钟刷新，Cloudflare 构建可能有延迟

### 现象 3：文章里图片裂图不显示

- 图片必须是**直接粘贴进飞书文档**的（飞书会真正保存它）
- 从网页上「复制图片」再粘贴有时只是链接，飞书里能看但机器人抓不到——**先把图片存到电脑，再粘贴进文档**
- 网页剪藏的文章：个别图片可能抓不下来，手动补一下

### 现象 4：正文显示 `**星号**` 这类符号

- 你可能在飞书里手打了 Markdown 符号。改用飞书自带排版（加粗按钮、标题样式），见 6.1 的表

### 现象 5：网站打不开 / 一直转圈

- Cloudflare 构建失败：Cloudflare 控制台 → Workers 和 Pages → 你的项目 →「部署」→ 看最新一次构建日志
- 构建命令/输出目录填错：回 3.2 检查（`npm run build` 和 `dist`）

### 现象 6：GitHub 网页打不开或很慢

- 国内网络访问 GitHub 本身不稳定，换个时间/网络多试几次；Actions 和 Cloudflare 不受影响，只有你自己打开 GitHub 网页时才受影响

## 第 9 章 · 改成你自己的样子

模板里是示例信息（李小白），改成你自己的。**不用装任何软件**，直接在 GitHub 网页上改：

1. 打开你的仓库，找到要改的文件，点进去
2. 点右上角的**铅笔图标**（✏️ Edit this file）
3. 改完点绿色「**Commit changes**」按钮，1～2 分钟后网站自动更新

### 优先改这三个文件

| 文件 | 改什么 |
| --- | --- |
| `src/config.ts` | 你的名字、邮箱、简介、社交账号（**第一个改这个**） |
| `src/pages/index.astro` | 首页的大标题、优势、获奖、工作经历（示例数据都标了注释，照格式换） |
| `astro.config.mjs` | 第 3 章拿到的网址，填到 `site:` 那行 |

### 内容文件不用手动管

`src/content/` 里的文章和作品文件都是同步脚本自动生成/删除的，你改了也会被下次同步覆盖——**内容永远去飞书里改**。
